feat!: release Motion Suite 3.5.1

Major update from 3.0.0 to 3.5.1 for Minecraft 1.21.11.

- Add Render Optimizer: fullbright (Night Vision/Gamma), no weather, no item bounce, hurt tilt/fire/cloud/particle/HUD toggles
- Add farm lag reducers: remove TNT, item drops, XP orbs, thrown items, far entity cull, block render cull (70 blocks), 29-group sound cull
- Add free look and command key macros (up to 4 slots) with per-server text
- Add smart blur, adaptive blend and render budget
- Add in-game hub (M) with all settings and key binds, plus ModMenu integration
- Add English and Vietnamese lang files
- Split config into per-feature classes with ConfigManager and ConfigSnapshot
- Restructure code into feature, core, ui, input and data packages with new mixins
- Move VulkanMod support into a separate src/vk source set
- Add unit tests for adaptive blend, command key config and sound groups
- Migrate Gradle to Kotlin DSL and update Loom 1.16-SNAPSHOT to 1.16.3
- Add docs/RELEASE.md

BREAKING CHANGE: /motionblur and /motioncamera are removed; /motionsuite now only provides hub and reload.
